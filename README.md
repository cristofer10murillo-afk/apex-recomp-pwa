# APEX RECOMP | Hybrid Fitness & Biometrics PWA

Aplicación Web Progresiva (PWA, Mobile-First, Dark Mode deportivo `#090D16` / `#111827`) diseñada para entrenamiento híbrido (**Fuerza Torso/Pierna 4 Días A/B + Insanity HIIT 63 Días**), biometría segmentaria (**Báscula Camry 8 Electrodos + Samsung Galaxy Watch 7**) y nutrición con **Ciclado de Carbohidratos**.

## Stack Tecnológico & Despliegue
- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS + Lucide React + Recharts.
- **Base de Datos Cloud + Offline:** Firebase Cloud Firestore (`apex-recomp-pwa-2026`) + `IndexedDB` + `localStorage`.
- **Producción:** Desplegado en Netlify (`https://apex-recomp-pwa.netlify.app`).
